# Final Experiment Evidence Package

This folder collects the final experiment evidence for the thesis project "Table Recognition in Document Images".

## Contents

| Folder | Purpose |
|---|---|
| 01_final_summaries | Final result summaries, error analysis, and revised short report files |
| 02_iou_annotation_quality | IoU-based annotation-quality analysis |
| 03_learning_curve_and_training_setup | Learning-curve summary and training setup evidence |
| 04_model_logs | Main model evaluation and prediction logs |
| 05_qualitative_examples | Selected qualitative examples and evidence matrix |
| 06_yolo_result_sources | YOLOv8 and YOLOv10 result source files |
| 07_tatr_result_sources | TATR result source files and threshold sweep outputs |
| 08_nemotron_result_sources | Nemotron result source files and YOLOX experiment config |

## Notes

- This package is for evidence organization.
- It does not contain large model checkpoints.
- It does not replace the full experiment folders on the VM.
- The selected qualitative examples are copies; original overlays remain unchanged.
